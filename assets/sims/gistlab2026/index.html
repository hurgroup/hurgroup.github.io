How to use in class

  1. Open a simulation. A question card appears first. Let students vote.
  2. Press Run it ▶ (or Space). Use 0.25× to watch the key moment slowly.
  3. Try the presets: Match the video, then the failure cases. Turn on Forces to show the arrows.
  4. Change one slider at a time and ask: what changed, and why?

Keyboard

SpacePlay / pause RReset →Step one frame SChange speed (2× → 1× → 0.5× → 0.25× → 0.1×) FForce arrows on/off PShow the question card again
