# IFAC WC 2026 OIT Webpage (Static)

This folder contains a single‑page website for the Open Invited Track (OIT):
**“Powered Transfemoral/Transtibial Prostheses: Control, Estimation, Personalization, and Clinical Translation.”**

## How to Use
1. Open `index.html` in any modern browser.
2. Replace organizer photos in `images/organizers/` with real headshots (use the same filenames).
3. Optional: Edit text directly in `index.html` (search for the `<!-- EDITABLE -->` markers).
4. The site uses Tailwind via CDN; an internet connection is required for styling. Content and images work offline.

## File Structure
- `index.html` — main page
- `assets/hero.svg`, `assets/favicon.svg` — graphics
- `images/icons/*` — section icons
- `images/organizers/*` — placeholder headshots
